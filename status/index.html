How the check works

Its own clock

The checker runs at 07:40, 12:40, 15:40 and 23:40 Istanbul time. Nothing it checks can trigger it, skip it or edit what it writes.

Facts only

It reads when each post actually appeared and when the scoreboard actually changed, then compares that with the deadline. It does not take any job's word for it.

Misses stay visible

A post that cannot pass its own data check before the deadline is not published. That day stays on the strip as missed.
