No agent signs off its own work, and the audit function reports to the orchestrator alone. Roles marked open are designed but not yet running.

Operating rules

01

Two keys on every output

Whoever drafts never publishes. A second agent re-pulls the numbers and only an approved draft goes out.

02

Fixed deadlines

Each deliverable has a time it must be out by. Preparation starts early so a draft can be sent back and still make it.

03

Audit stays outside

The auditors run on their own clock and read facts, not self-reports. A miss stays on the record.
